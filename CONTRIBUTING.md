# Contributing

Bug reports, documentation improvements, and focused pull requests are welcome.

For a bug, include the mod version, game version and Steam build, operating system, installation method, expected behavior, and exact error or steps to reproduce. Explain whether the issue occurs with other mods enabled. Remove personal paths and account identifiers from logs. Do not attach private campaigns or game files.

Before a code change, read the [development guide](docs/DEVELOPMENT.md). Keep the change focused and run the checks relevant to the behavior. State what you tested and whether it used synthetic fixtures or a real game installation. New game compatibility needs evidence from that build; a passing source test alone does not establish compatibility.

Preserve normal game costs, ownership, activation choices, installer ownership checks, backups, recovery, and release verification. Discuss a substantial behavior or architecture change in an issue first. Never commit game bundles, saves, private keys, credentials, or copied code without a compatible license and attribution.

By submitting a contribution, you agree that your original contribution may be distributed under this project's MIT License. Keep existing copyright and license notices. For a fork, use its own name and release identity so users can distinguish it from Little Guy Dev's signed releases.

Report security issues using [SECURITY.md](SECURITY.md).

# Transport Autopilot 1.1.1

- Officially tested with Geoplanetical 1.1.4 (Steam build 26709373) on native Mac.
  The package includes Windows installers; native Windows 1.1.4 gameplay has not
  been verified.
- Updated game hooks and preserved existing campaign settings, budgets and
  projects.
- Later stable game versions can be tried when the required code hooks and
  integrity checks pass. A new version number alone no longer blocks installation;
  compatibility with future game behavior is not guaranteed.
- Run the included installer once after downloading this release to activate the
  new signed updater capability. The previous runtime and publisher key are kept.

# Transport Autopilot 1.1.0

- A clearer panel with Overview, Settings and Projects tabs. See what needs
  attention, adjust your choices, and follow construction in one place.
- Choose Keep expanding to keep building selected roads, freeways and rail
  even when current transport needs are covered. Build when needed remains
  the default. Existing campaigns keep it until you choose and save another mode.
- Clearer reports explain transport problems, available money and work already
  under way. Recent project starts are shown separately from finished work.
- Unsaved settings stay available when you switch tabs or reopen the panel.
  Saving settings and starting construction are separate actions.
- Faster installer checks, stronger Windows security checks, and a fix for
  reinstalling after removal. Backups and recovery checks are still included.

- Automatic updates can run before the game starts on Windows and Mac. Install
  once; the installer sets Steam's Launch Options automatically. Save and close
  other Steam games first; Steam may briefly close and reopen during setup.
  Ordinary updates to that selected folder apply at the next Steam launch.
- Both mods share one setup for the same game. Removing either mod stops its
  automatic updates without turning off updates for the other.
- Update files are verified before use, and backups and recovery checks remain.
  A failed update stops the game launch and shows an error.

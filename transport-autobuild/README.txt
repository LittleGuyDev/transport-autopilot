TRANSPORT AUTOPILOT — AUTO TRANSPORT CONSTRUCTION 1.1.0
By Little Guy Dev. Made for Geoplanetical 1.1.3.

WHAT'S NEW IN 1.1.0
- A clearer panel with Overview, Settings and Projects tabs. See what needs
  attention, adjust your choices, and follow construction in one place.
- Choose Keep expanding to keep building selected roads, freeways and rail
  even when current transport needs are covered. Build when needed remains
  the default. Existing campaigns keep it until you choose and save another mode.
- Clearer reports explain transport problems, available money and work already
  under way. Recent project starts are shown separately from finished work.
- Unsaved settings stay available when you switch tabs or reopen the panel.
  Saving settings and starting construction are separate actions.
- Automatic updates before Steam starts the game, with Steam Launch Options
  set up automatically during the first manual install. No repeated installer steps for
  ordinary updates downloaded to the selected mod folder.
- Faster installer checks, stronger Windows security checks, and a fix for
  reinstalling after removal. Backups and recovery checks are still included.

UPDATING FROM 1.0.0
Save and close the game. To set up this release, run install.bat on Windows
or install.command on Mac once and finish the Steam setup below. Future
ordinary updates apply before the next Steam game launch. Your saved settings, other mods and
construction already in progress are kept. The new Keep expanding option only
starts applying after you choose it and save your settings.
If you tried an earlier test build that also showed 1.1.0, run this installer
to update it too. The installer can tell the two builds apart.

WHERE TO FIND IT
Open Transport Room > Build > Transport Autopilot. You can also find it in
Settings > Game, or search for Transport Autopilot with Command/Control+K.
Manage mods lists Transport Autopilot 1.1.0. After enabling or disabling the
mod there, restart the game. Disabling keeps your settings and existing projects.
Load order changes the position shown in Manage mods. It does not change how
the installer applies the mod. View on Workshop opens this mod's Steam page.

USE IT
The panel has three tabs: Overview, Settings and Projects.
1. In Settings, choose roads, freeways, rail, gas pipelines, oil pipelines
   and/or ports. You must select pipelines and ports to allow those projects.
2. Choose Build when needed to cover current demand and your spare-capacity
   target. Choose Keep expanding to continue selected road and rail building
   beyond that target. The game still limits where and how much can be built.
3. Set a monthly construction budget and a minimum cash reserve. Values are
   BILLIONS of the currency shown: 0.1 means 100 million.
4. Choose spare land capacity to keep (default 20%; range 5–50%).
5. Turn on automatic construction and click Save settings.
6. Click Check and build now to review needs and start affordable projects,
   or let game days pass. Automatic reviews continue with the panel closed.

Saving settings does not start construction. Update report refreshes the
information without starting projects. Unsaved edits remain while switching
tabs or reopening the panel in the same campaign.

New campaigns start with automation off and only roads, freeways and rail
selected. Settings are saved separately for each campaign and country.

WHAT TO EXPECT
Normal costs, materials and construction times apply. A project that has
started does not add capacity until it finishes. Projects shows active work
and up to 32 recent automatic starts; a start is not a completion record.

Build when needed stops once demand and your spare-capacity target are covered.
Keep expanding can continue selected road, freeway and rail building. Pipelines
and ports are only expanded when they can help meet demand in either mode.
Useful transport upgrades are considered before optional extra land building.

The budget is a spending limit, not a promise to spend the whole amount.
It covers estimated monthly costs for all your active transport projects,
including projects you started manually. Unpaid costs, available cash, suitable
sites and construction limits can prevent more work. The mod pauses if you do
not control the government. It starts at most 8 projects a day and keeps at
most 64 of its transport projects active at once.

Enough roads at home does not mean every shipment has a usable route. Foreign
infrastructure, blockades, damage and political restrictions can still limit
transport. The mod only builds infrastructure you control. Some routes need
several upgrades together or work in another country, so 100% delivery cannot
be guaranteed. It waits when the game cannot provide enough information to
choose useful work safely.

Lowering the budget, changing building mode or turning automation off does not
cancel existing projects. Your cash reserve is checked before new work starts;
it does not stop other government spending.

INSTALL FROM STEAM WORKSHOP
Subscribe to Transport Autopilot and wait for Steam to finish downloading it.
Save and close Geoplanetical before installing the mod.

You need Python 3.8 or newer. If you already installed Python, skip this step.
Otherwise, download and run its installer for your computer:
  Windows: https://www.python.org/downloads/windows/
  Mac: https://www.python.org/downloads/macos/

WINDOWS
1. Open File Explorer (Windows key + E).
2. Press Ctrl + L to select the address bar at the top. Paste this whole line
   and press Enter:

C:\Program Files (x86)\Steam\steamapps\workshop\content\940230\3839206386

3. Double-click install.bat.
4. In the window that opens, check the game location. Save and close other Steam
   games before pressing Enter; Steam may briefly close and reopen.
   Keep the window open. Installation can take several minutes.
5. Wait for installation and automatic-update setup to finish. Then close
   the installer and start the game through Steam.

If Windows hides the file ending, the file may appear as just "install".
Choose View > Show > File name extensions to see its full name, install.bat.
If the window says Python is missing, install Python using the link above,
then double-click install.bat again.

MAC
1. Open Finder and press Shift + Command + G.
2. Paste this whole line into the Go to Folder box and press Return:

~/Library/Application Support/Steam/steamapps/workshop/content/940230/3839206386

3. Double-click install.command.
4. In the window that opens, check the game location. Save and close other Steam
   games before pressing Return; Steam may briefly close and reopen.
   Keep the window open. Installation can take several minutes.
5. Wait for installation and automatic-update setup to finish. Then close
   the installer and start the game through Steam.

IF THE FOLDER DOES NOT OPEN
First, check that you subscribed and Steam finished downloading the mod.
If your Steam library is in a different location, try this:
1. In Steam's Library, right-click Geoplanetical.
2. Choose Properties > Installed Files > Browse.
3. Go up two folders to steamapps, then open workshop > content > 940230 >
   3839206386. Run install.bat on Windows or install.command on Mac.
If it still isn't there, make sure Steam finished downloading the mod, then
ask for help finding your Steam library.

If Finder will not open install.command, open Terminal (Applications > Utilities).
Type cd and a space, drag the mod folder into Terminal, and press Return.
Then type sh install.sh and press Return.

The installer heading and final installed version should say Transport Autopilot
1.1.0. The number under Existing Transport Autopilot identifies the copy
currently installed. Keep the downloaded files together in this folder.

AUTOMATIC UPDATES — SET UP BY THE INSTALLER
The installer sets Geoplanetical's Steam Launch Options automatically. No copying
or pasting is normally needed. Save and close other Steam games first: before
confirmation, the installer warns that Steam may briefly close and reopen.
It never force-quits Steam and stops if Steam cannot close normally.

Setup checks the selected Steam account and game, keeps a private backup, and
preserves plain game flags. Unknown launch wrappers or conflicting accounts are
left unchanged. If setup stops, follow its error, close Steam or sign in to the
right account, resolve your own custom options if needed, then rerun the installer.
The mod may already be installed. A recognized exact older updater line is adopted.

Steam will check the downloaded mod files and apply supported updates before
starting the game. Wait for Steam's downloads to finish first. Keep the mod
folder where it was when you installed it: this is where updates are checked.
An update may delay the game starting while files are checked and backed up.

If you use both Transport Autopilot and Tourism Dashboard for the same game,
install each once. They share one update check and one Steam Launch Options
entry. Setup does not stack a second wrapper. Each mod keeps its own files
and can be removed independently.

For updates delivered by Steam, run the first installer from the downloaded
Workshop folder. If you install from a standalone ZIP, the updater only follows
that extracted folder. It does not find or download newer ZIPs for you. Replace
that folder with a complete newer release to make it available for updating.

The check verifies that update files came from Little Guy Dev and have not
changed, then uses a private working copy. Backups, game compatibility checks
and recovery remain in place. If a download is incomplete, verification fails,
or the game is unsupported, the game launch stops with an error instead of
continuing through that problem. Its error window shows where last-error.txt
was saved; keep that message or file when asking for help.

The installer also prints the location of a Play Geoplanetical shortcut. It
checks updates and opens Steam. Keep the Steam Launch Options line in place
when using the shortcut too. No background service or administrator setup is
needed. Ordinary automatic updates do not restart Steam to change settings.

PREFER MANUAL UPDATES?
For manual updates, run the installer when you want to apply an update.
From a command window in the mod folder,
use install.bat install --no-automatic on Windows or
sh install.sh install --no-automatic on Mac to skip automatic-update setup.
That option skips new setup; it does not turn off registration already saved.
To return to manual updates, remove the generated updater line from Steam
Launch Options and use Steam's normal Play button. Keep any other custom options.
The separate Play Geoplanetical shortcut still checks updates if you use it.

After moving the game, Python or the mod folder, you may need to run setup
again. A future game update or major updater change may also need a new manual
installer setup. Follow that release's instructions. Do not remove
safety checks to get past an update error.

IF YOU ALREADY USE OTHER MODS
This installer installs only Transport Autopilot. Existing other mods are kept
as they are. It does not look for other mods to download or install. No separate
compatibility check is required just because you use another mod. An unsupported
or conflicting game change makes this installer stop with an explanation.

OPTIONAL CHECK WITHOUT INSTALLING
From a command window in the mod folder, run:
  Windows: install.bat check
  Mac: sh install.sh check
This checks the selected game and Transport Autopilot files without installing.
For a custom game location, add its path:
  Windows: install.bat check "C:\path\to\Geoplanetical"
  Mac: sh install.sh check "/path/to/Geoplanetical.app"
To install at that location, replace check with install.

If a command shows ERROR, keep the exact message or take a screenshot so it can
be checked. Address that message before trying again.

INSTALL FROM A STANDALONE ZIP
On Windows, right-click the ZIP and choose Extract All. Open the extracted
folder, then the Transport-Autopilot folder inside it. Double-click install.bat.
On Mac, extract the ZIP and double-click install.command in that folder, or use
the Terminal steps above. Steam Workshop downloads are already unpacked.
Keep the extracted folder in place for automatic updates and uninstalling.
For Steam-delivered updates, set up from the Workshop folder instead.

UNINSTALL
1. Save and close Geoplanetical.
2. Open the mod folder using the same File Explorer or Finder path above.
3. Double-click uninstall.bat on Windows or uninstall.command on Mac.
4. Check the game location and press Enter/Return to confirm. Wait for the
   removed message, then press a key/Return to close the installer.
5. You can now unsubscribe in Steam if you want to remove the downloaded files.

Run the uninstaller before unsubscribing. Unsubscribing alone does not remove
code already installed in the game. Your other mods, saved settings and
construction already in progress are kept. Removing this mod also stops its
automatic updates, so it will not be installed again at the next Steam launch.
If you still use Tourism Dashboard, its automatic updates continue.
Final removal may briefly close and reopen Steam; close other Steam games first.
It restores the earlier Launch Options only if the current entry is still ours.
Later user changes are preserved, and runtime files stay if another mod needs them.

Mac Terminal alternative: follow the Terminal steps above, but type
sh install.sh uninstall instead.

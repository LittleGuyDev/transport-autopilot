# Security reports

For a suspected vulnerability in the installer, updater, or release verification, use **Report a vulnerability** in this repository's Security tab when available. If private reporting is unavailable, open an issue asking for a private contact without posting exploit details or secrets.

Include the affected version, operating system, impact, and minimal reproduction steps. Remove personal paths, account identifiers, and private data. Do not upload game files, campaigns, credentials, or signing keys.

Official packages authenticate updates with a publisher signature. The private signing key is never part of this repository or a release package; the verification public key is intentionally public. A source build or fork is not an authenticated Little Guy Dev release. Do not bypass signature or game compatibility checks to work around an installation error.

Security fixes are assessed against the current release. Older releases and unsupported game versions may require an upgrade. There is no guaranteed response deadline.
